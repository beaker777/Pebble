Explain 的 rows 字段不会触发全表扫描, 它的估算是基于 **采样统计** 和 **索引下潜** 的.

## 采样统计

MySQL 会在后台随机抽取数据页, 然后统计这些页中的数据行数.

然后根据公式 `平均每页行数 * 总页数` 来推算出全表的总行数.

## 索引下潜

当 SQL 语句是范围查询时, MySQL 会通过索引下潜来估算 rows. 在左右边界各 "潜入" 一次 B+ 树.

如果两个边界所在的数据页距离很近, MySQL 会直接数出行数. 如果距离较远会通过 `间隔页数 * 平均每页行数` 来估算.
