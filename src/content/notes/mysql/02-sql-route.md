volume: mysql

updatedAt: 2026-11-24
---

**第一步 连接器**

连接器负责建立客户端到 MySQL 的 TCP 连接, 校验用户名和密码.

**第二步 查询缓存**

系统会先查询缓存, 命中缓存就直接返回. 由于缓存更新过于频繁, **MySQL 8.0** 已经废弃了该功能, 现在会直接进入下一步.

**第三步 分析器**

分析器会对 SQL 语句做词法和语法分析. 从 SQL 语句中提取关键词并判断是否有语法错误.

**第四步 优化器**

优化器会制订它任务最好地执行计划, 决定走哪个索引, 多表查询的联合顺序.

**第五步 执行器**

执行器会根据执行计划, 调用存储引擎层的 API 接口.

**第六步 存储引擎**

存储引擎负责真正的数据存储与读取, 将数据结果返回给执行器, 再由执行器返回给用户.
