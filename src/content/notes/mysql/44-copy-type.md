# 异步复制

主库提交事务后直接返回成功, 不等待从库.

优点是速度最快, 缺点是存在数据丢失的风险, 一旦主库宕机, 未同步的 binlog 就会丢失.

## 半同步复制

主库会等待第一个从库返回确认后, 才算完成.

优点是极大的保证了数据一致性, 缺点是增加了网络延迟.

## 同步复制

需要等待全部从库返回确认, 才算完成.

优点是实现了强一致性, 缺点是速度取决于最慢的从库, 性能最差.
