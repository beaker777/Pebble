最左前缀法则是 MySQL 中联合索引的核心规则, 底层原理是 B+ 树的有序性.

以索引 (A, B, C) 为例, 最左前缀法则要求:

- 必须从最左列开始, 如果跳过最左列会导致索引失效, 直接走全表扫描.

- 如果跳过中间列, 比如 `a = 1 AND c = 2`, 此时只有 a 会走索引, c 只作为过滤条件.

- 范围查询后的查询条件不会走索引, 比如 `a = 1 AND b > 3 AND c = 4`, 此时只有 a b 会走索引, c 只作为过滤条件.

> 所谓的 "走索引" 是指可以利用 B+ 树的有序性通过二分查找快速定位.
> 
> 对于不能走索引的列会在索引下推阶段过滤掉一部分, 也不是完整的全部返回回去.
