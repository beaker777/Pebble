## 回表

当使用辅助索引时, 如果查询内容没有完全包含在辅助索引中. 此时会先通过辅助索引获取主键, 再去主键索引中查询到对应的数据行.

这个过程就叫作 **回表**, 会导致额外的磁盘 IO 开销.

## 覆盖索引

覆盖索引是一种设计索引的方式, 比如我们要经常执行:

```
SELECT age FROM user WHERE name = "xxx";
```

此时可以建立 (age, name) 的索引, 这样检索的时候就能直接获取到 age 无需回表, 大大提升性能.
